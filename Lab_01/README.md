# Lab 1 – GitHub Setup

**Course:** GEOG 678 – Web GIS  
**University:** Texas A&M University

## Overview

The purpose of this lab was to become familiar with GitHub as a platform for organizing, documenting, and sharing GIS coursework. This lab introduced the fundamentals of repository creation, file organization, version control, and Markdown documentation.

## Objectives

- Create or access a GitHub account.
- Establish a public repository for GEOG 678.
- Organize laboratory assignments into individual folders.
- Create README.md files to document each laboratory.
- Provide the course instructor access to the repository.

## Lab Activities

1. Accessed GitHub using an existing account.

## Conclusion

This lab established a centralized GitHub repository for organizing and documenting GEOG 678 coursework. The repository provides a structured environment for storing laboratory assignments, sharing Web GIS projects, and maintaining documentation throughout the course. GitHub's version control capabilities also allow changes to be tracked as laboratory assignments are completed.
