
# Lab 2 – ArcGIS Online Web Mapping

**Course:** GEOG 678 – Web GIS  
**University:** Texas A&M University

## Overview
The purpose of this lab is to gain experience using ArcGIS Online to create, configure, and share an interactive web map. This lab also introduces the use of mobile GIS applications for viewing and collecting geographic data.

## Objectives
- Become familiar with ArcGIS Online.
- Complete the ArcGIS Online web mapping tutorial.
- Create and share a web map for data collection.
- Access the published web map using a mobile GIS application.
- Document the completed work in GitHub.
