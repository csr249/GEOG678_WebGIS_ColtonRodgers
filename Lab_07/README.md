# Lab 7 – ArcGIS StoryMaps

**Course:** GEOG 678 – Web GIS  
**University:** Texas A&M University

## Overview

The purpose of this lab is to gain experience developing interactive geographic narratives using ArcGIS StoryMaps. This lab introduces the process of combining maps, text, images, and other multimedia elements to communicate geographic information through web-based storytelling.

## Objectives

- Become familiar with ArcGIS StoryMaps.
- Create interactive geographic narratives.
- Integrate maps, text, and multimedia content.
- Publish and share web-based StoryMaps.
- Document completed StoryMaps using GitHub.
