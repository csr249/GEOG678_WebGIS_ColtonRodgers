## Course Overview

This repository contains laboratory assignments completed as part of GEOG 678 – Web GIS at Texas A&M University.

The coursework focuses on web-based geographic information systems, interactive mapping applications, JavaScript programming, geographic data visualization, and web development.

Each laboratory assignment is organized into an individual folder containing a README.md file, supporting code, screenshots, and project deliverables.
