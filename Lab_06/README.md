
# Lab 6 – Advanced JavaScript Mapping

**Course:** GEOG 678 – Web GIS  
**University:** Texas A&M University

## Overview

The purpose of this lab is to expand upon introductory JavaScript web mapping concepts by developing more advanced interactive mapping applications. This lab provides additional experience working with web mapping tutorials, geographic data, and custom map development.

## Objectives

- Expand knowledge of JavaScript web mapping.
- Complete two advanced web mapping tutorials.
- Develop a custom interactive web map.
- Incorporate geographic data into web mapping applications.
- Test and display web maps in a browser.
- Document and organize project files using GitHub.
