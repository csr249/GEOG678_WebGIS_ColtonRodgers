# Lab 8 – Interactive Charts

**Course:** GEOG 678 – Web GIS  
**University:** Texas A&M University

## Overview

The purpose of this lab is to gain experience developing interactive web-based data visualizations using ArcGIS Dashboards, D3.js, and Highcharts. This lab introduces techniques for displaying geographic and statistical information through interactive dashboards and charts.

## Objectives

- Create an interactive ArcGIS Dashboard.
- Develop web-based charts using D3.js.
- Create interactive charts using Highcharts.
- Integrate HTML and JavaScript for data visualization.
- Publish and share interactive web applications.
- Document project results using GitHub.
